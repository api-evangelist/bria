# Bria AI Platform

> Enterprise-grade visual AI API building blocks. Bria provides safe, controllable and transperent visual AI capabilities. All endpoints are trained on 100% licensed data - commercially licensed, commercially safe, and indemnified.

This file indexes the Bria platform web application and visual AI API building blocks. Application links open product UI; API links open per-endpoint `llms.txt` files with schemas, examples, and the interactive sandbox. API entries are generated from the same registry as the API Building Blocks UI.

For platform overview, authentication, and agent integration, see the documentation hub: <https://docs.bria.ai/llms.txt>
